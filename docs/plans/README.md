# Specs and plans

New work uses the singular [idea](../idea/README.md), [spec](../spec/README.md),
[plan](../plan/README.md) and [sprint](../sprint/README.md) directories.
This legacy directory and the records below remain historical; existing links
and document contents are retained.

The engineering method (AGENTS.md section 3) writes two files per change:

- `YYYY-MM-DD-<topic>-design.md`: the agreed spec (goal, scope, behaviour, data, risks, docs to update, version impact).
- `YYYY-MM-DD-<topic>-plan.md`: the test-first plan (numbered tasks with the failing test, files, commands and expected results).

They are reviewed in the pull request with the change and stay as the record of why the code looks the way it does. Customer-neutral: Caldova only.
