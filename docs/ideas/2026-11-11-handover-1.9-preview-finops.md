## Outcome

Bring the process ontology, standard-entity grounding, semantic data layer and
data-product improvements from the received 1.9.0 source into our hardened
private repository. Keep `frontier-finops` available but optional, Preview and
unused until the user explicitly understands its limitations.

This does not make Fabric dependencies GA, turn unchecked mappings into verified
ones or publish a release. The incoming process skill prepares import/design
files; it does not provision a tenant.

## Alternatives

Bundled-but-gated FinOps keeps one plugin/install contract and updates existing
installations with the Preview instructions. A separate package variant/add-on
would add migration and identity handling; it is not the selected design.
A raw tree overwrite would discard reviewed privacy, scope, accessibility,
documentation and distribution safeguards and is rejected.
