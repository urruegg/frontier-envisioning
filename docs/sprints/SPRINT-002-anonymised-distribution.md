## Scope and evidence

The maintainer explicitly asked to anonymise the current enterprise-account
references and prepare a clean plugin package while keeping the repository
private. The audience form was unavailable; assume Microsoft-internal
distribution. No new formal approval, protected label or external clearance
is inferred. No implementation was delegated.

Initial inventory: eighteen literal references in eleven tracked files, all
outside the plugin. Both existing 1.6.1 ZIPs had zero literal account members,
but the complete ZIP included the internal analysis. The current intake owner's
redaction is explicit; all 249 original file records retain their canonical hash.
The original receipt and account evidence remain in private history.

The first tests reproduced the missing privacy guard and unwanted bundle
analysis entry. The first combined green run passed 63 tests and 269 subtests.
A separate added ZIP-comment regression then failed before comment inspection
was wired. Additional encoded/underscore identity, renamed classified-document
and root-level nested secret-file cases were reproduced before their fixes.

## Final local verification

- The final combined distribution/release-tools/tools-core/docs-contract run
  passes: 65 tests and 274 subtests.
- `python tools/dev.py check --strict`: `ALL GATES PASSED`; 172 tests,
  385 subtests and 41 DOM tests. One expected skip: unreleased 1.6.1 has no
  current release manifest. Old release/raster records and protected controls
  remain unchanged.
- Case-insensitive current tracked-content and finished-archive inspection:
  zero literal legacy enterprise identifiers. The actual identifier is supplied
  only to an out-of-repository verification helper; tracked tests use synthetic
  examples. The physical workspace path and private history are not rewritten.
- Exact inspection boundaries were exercised: eight MiB of text passes,
  eight MiB plus one byte fails; three ZIP containers pass, a fourth fails.
- A dedicated `dist/distribution-1.6.1` handoff contains exactly the current
  plugin ZIP, complete ZIP and checksums, generated by the normal build scripts.
  The complete ZIP has eleven entries and no analysis/intake files; its plugin,
  PRD and solution-design bytes match current source.
- Archive/member names, content, nested ZIPs and comments pass the shared
  privacy guard and the exact identifier check; both ZIP checksums match.
- A temporary extraction passes offline `prepare_install.py`: verified=true,
  no problems, seven skill plans and seventy verified skill files. The temporary
