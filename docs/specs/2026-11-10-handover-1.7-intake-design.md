## 3. Integration decisions and error behaviour

- Port the received feature changes, not whole files where current hardening
  differs. Preserve the current modal shell, inert-state/focus lifecycle, roving
  labelled tabs, pressed filters, SVG control exposure, interactive text opacity,
  bounded sticky agent layout, adaptive contrast, targets and small-screen reflow.
- Keep the blueprint schema and existing keys compatible; missing optional
  parts/PRD/risks/board/contribution objects must not crash or fabricate evidence.
- PRD requirement IDs come from the complete blueprint's canonical agent order;
  filtering agents for a scaffold does not renumber the surviving requirements.
  Authored presentation fields survive rederivation. Compare semantic content
  between Markdown outputs; their headings need not be byte-identical.
- Risk ratings are finite integers 1-5, excluding booleans. Invalid authored
  ratings use the existing report channel with an explicit warning; strict mode
  fails. Invalid feedback is reported and does not silently mutate ownership or
  report a successful rating update.
- Existing authored and workshop risk IDs are preserved. Repeated derivation
  does not duplicate entries; source changes must not silently apply an old
  verdict to a different risk. Retain the supplied demo IDs where inputs are
  unchanged; test edited/reordered source risk points.
- New control rerenders retain useful keyboard focus and accessible feedback.
  Filtering/closing a selected risk must not show a stale, hidden selection.
- Customer-audience generation must remove internal evidence and internal-derived
  attendee/risk/PRD content from embedded data and downloadable documents. A removed
  source ID alone is not sanitisation. Test synthetic unique markers, not real data.
- CSV fields need quoting for delimiters, newlines and Unicode, plus safe handling
  of spreadsheet formula prefixes. Downloaded files are tested, not button presence.
- Keep stdlib/offline plugin behaviour and proper explicit reporting. No broad
  catch, silent acceptance, test suppression or permissive fallback to pass gates.
